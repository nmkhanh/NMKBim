# ĐẶC TẢ HỆ THỐNG ĐA NGÔN NGỮ (I18N: EN, DE, JA)

Hệ thống hỗ trợ 3 ngôn ngữ:
1. **Tiếng Anh (`en`)** - Ngôn ngữ mặc định
2. **Tiếng Đức (`de`)** - Tiêu chuẩn ngành kỹ thuật/xây dựng Châu Âu
3. **Tiếng Nhật (`ja`)** - Tiêu chuẩn ngành BIM/CAD Châu Á (cần hỗ trợ phông ký tự CJK như Noto Sans JP, Meiryo)

---
